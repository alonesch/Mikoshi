# MVP local da Mikoshi

**Objetivo:** seleção de projeto, identidade portátil, memória canônica, bootstrap revisável, working context e execução real via Codex CLI.

**Arquitetura:** serviços locais no main; contratos tipados no preload; React para revisão e execução. JSON schema v1 é uma escolha desta implementação, sem banco ou cloud. `.mikoshi/project.json` guarda apenas identidade portátil; memória, REVIEW.md e estado operacional ficam em `app.getPath('userData')`.

**Especificação:** contexto consolidado fornecido pelo usuário em `mikoshi_contexto_completo.txt`, especialmente seções 28 e 30. Histórico e propostas futuras não são funcionalidades já implementadas.

## Restrições

- Electron sandbox, contextIsolation e API mínima preservados.
- Nenhuma leitura de arquivos nativos de autenticação ou sessões.
- Contexto e saídas passam por sanitização determinística; revisão antes de atualizar memória.
- Providers começam por Codex, com permissões explícitas e sem bypass de sandbox.
- Nenhuma cloud, API remota, sincronização automática ou canvas complexo.
- Dados pessoais fora dos binários; nenhuma publicação ou push.

## Pontos de revisão

Identidade em outro path; documentos com segredos; symlinks e arquivos grandes; diffs concorrentes; cancelamento/encerramento; provider indisponível; memória não aplicada automaticamente; importação malformada; dados preservados pelo instalador.

## Decisões

Execução no checkout atual, autorizada pelo usuário. Sem pacotes vazios. Bootstrap inicial determinístico a partir de documentação e manifesto: produz candidatos, sem inferir motivos a partir do código. Extração de memória do Codex usa resposta estruturada com revisão, sem reescrita total.
